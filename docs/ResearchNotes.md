# Investigación del producto

## Hipótesis

- Una vista espacial reduce dudas sobre orientación y distancia.
- La comparación visual ayuda a comunicar el valor de zonas premium.
- Un flujo compatible con lista HTML mantiene utilidad cuando 3D no está disponible.

## Métricas para una prueba moderada

- Tiempo para identificar lado, sección y cercanía al terreno.
- Porcentaje de usuarios que cambian de zona después de ver la perspectiva.
- Confianza declarada antes y después de la vista 3D.
- Tasa de finalización del flujo simulado y errores de interacción.

## Riesgos por validar

Precisión percibida de la vista, rendimiento móvil, nomenclatura real, accesibilidad de controles 3D y expectativas creadas por una simulación.
