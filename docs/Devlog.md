# Devlog

## 2026-07-28

### Objetivo

Crear la primera entrega funcional de Quisqueya 3D.

### Trabajo realizado

Inicialización Next.js, escena geométrica, secciones, cámara, asientos, flujo simulado, adaptadores, estado, diseño responsive y documentación.

### Problemas encontrados

El nombre de la carpeta raíz no era válido como nombre npm y el editor de parches no pudo iniciar por una limitación del sandbox de Windows.

### Soluciones aplicadas

El scaffold se generó en una subcarpeta con nombre válido y se trasladó a la raíz. Los archivos se escribieron dentro del workspace mediante PowerShell con privilegio aprobado.

### Capturas agregadas

Pendientes después de la revisión visual local.

### Decisiones tomadas

No depender de fuentes, HDR, logos ni imágenes externas. Mantener el GLB futuro detrás de una bandera explícita.

### Próximo paso

Validar referencias reales, escala y nomenclatura con fuentes autorizadas antes del modelo Blender.
